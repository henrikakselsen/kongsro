Kongsro

Chrome-utvidelse som skjuler kongelig mediestorm (dødsfallsbølge) på utvalgte norske nettaviser. Alt filtreres lokalt i nettleseren.

Lenker

  • Personvernerklæring (privacy policy)
  • Kildekode på GitHub
  • Installasjon: Chrome Web Store (kommer)

Støttede nettsteder

  • VG, Dagbladet, Aftenposten, NRK, TV 2, Nettavisen
  • E24, ABC Nyheter, Dagsavisen
