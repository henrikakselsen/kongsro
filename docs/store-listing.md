# Chrome Web Store listing — Kongsro

## Title

Kongsro

## Short description (≤132 chars)

Skjuler kongelig mediestorm på VG, Dagbladet, Aftenposten, NRK, TV 2 og Nettavisen.

## Detailed description

Kongsro demper «overkill»-dekning rundt kongelige hendelser (inkl. dødsfallsbølger) på de største norske nettavisene.

**Hva den gjør**
- Skjuler artikkelkort og overskrifter som treffer lokale norske nøkkelord knyttet til kongehuset og sørgedekning.
- Fungerer på VG, Dagbladet, Aftenposten, NRK, TV 2 og Nettavisen.
- Du kan skru filtrering av globalt eller per nettsted i popup-menyen.
- På artikler kan du velge «Vis likevel» for den aktuelle siden.

**Viktig**
- Filteret er **aggressivt** med vilje: det er bedre å skjule for mye enn for lite.
- Alt skjer lokalt i nettleseren. Ingen konto. Ingen sporing. Ingen sky-analyse.

**Slik bruker du den**
1. Installer fra Chrome Web Store.
2. Åpne en støttet nyhetsside.
3. Klikk Kongsro-ikonet for å justere innstillinger.

## Category

News & Weather (or Productivity)

## Single purpose

Hide royal/news-overkill coverage on selected Norwegian news sites.
